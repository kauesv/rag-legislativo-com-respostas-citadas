# Golden set v1

`golden.jsonl` contains 50 questions. Expected references use the same canonical proposition form as ingestion (for example, `PL 4513/2020`); the numeric Câmara ID remains the database and API `document_id`. Answerable references are grounded in official Câmara materials for PL 4513/2020, PL 2338/2023, PL 2628/2022 and PL 2630/2020. Ambiguous examples list multiple expected propositions; five out-of-domain examples expect abstention.

The set is a starter baseline, not a representative sample of all legislative topics. Recheck expected references and refresh the version when the corpus period or benchmark questions change.
